# For A Cure Foundation

A React TypeScript application for the For A Cure Foundation website.

## Getting Started

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Start development server:**
   ```bash
   npm start
   ```


## Deploy

1. Build for production and then push all changes
   ```bash
   npm run build
   ```

2. Select 'Update from Remote' and 'Deploy Head Commit' on cPanel under Git Version Control
